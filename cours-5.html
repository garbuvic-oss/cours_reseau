DNS et messagerie SMTP

Deux services fondamentaux : traduire des noms en adresses, puis acheminer le courrier électronique.

Du fichier HOSTS.TXT au DNS

Les humains retiennent des noms, les machines manipulent des nombres. Un fichier central HOSTS.TXT suffisait au début ; dans les années 80 il a atteint ses limites, d’où le DNS hiérarchique.

FichierRôle
/etc/hostsAssociations IP et noms locales (127.0.0.1 localhost)
/etc/resolv.confnameserver : serveur à interroger ; search : domaines ajoutés aux noms courts

Concepts

  • FQDN : nom complet et non ambigu, terminé par un point (www.uca.fr.).
  • TLD : domaine de premier niveau (fr., com., org.).
  • Zone : périmètre de connaissance d’un serveur (., fr., uca.fr.). Elle ne connaît que ses fils.
  • Délégation : fr. sait seulement quel serveur gère uca.fr. ; le propriétaire gère sa zone et peut en déléguer une partie.
  • Récursion : interroger tour à tour plusieurs serveurs. Résolveur : bibliothèque locale qui interroge le DNS.
  • Autorité : un serveur autoritaire renvoie des données à jour ; un cache répond « non-authoritative ».

La vie d’une requête DNS

Résolution de iutweb.u-clermont1.fr avec un cache vide.

  1. Résolveur → serveur DNS local
    Le cache est vide.
  2. Serveur racine
    Ne connaît pas la réponse, indique les serveurs de fr. (NS e.ext.nic.fr., d.ext.nic.fr. …).
  3. Serveur de fr.
    Indique les serveurs de u-clermont1.fr. (ns1.clermont-universite.fr. …).
  4. Serveur de u-clermont1.fr.
    Répond : CNAME vers cassiope.u-clermont1.fr., sans AAAA.
  5. Bascule en IPv4
    Nouvelle question de type A : cassiope.u-clermont1.fr. A 193.49.118.248.
  6. Navigateur
    Reçoit 193.49.118.248 et ouvre une connexion sur le port 80.

Glue records : pour joindre e.ext.nic.fr. alors que fr. n’est pas encore résolue, le parent fournit les A/AAAA dans la section ADDITIONAL. C’est la seule duplication d’information du DNS.

Observer la résolution complète

$dig +trace +all iutweb.u-clermont1.fr AAAA
  • digInterroge le DNS.
  • +traceSuit la délégation depuis la racine, comme un résolveur.
  • +allAffiche toutes les sections (question, réponse, autorité, additionnelle).
  • iutweb.u-clermont1.frNom à résoudre.
  • AAAAType d’enregistrement demandé.

Résolution inverse : dig -x <IP> construit le nom in-addr.arpa. (ou ip6.arpa.) automatiquement.

Bonnes pratiques : au moins 3 serveurs autoritaires (maître/esclaves), DNSSEC pour signer les zones, split horizon pour répondre différemment selon l’origine (IP publique à l’extérieur, privée en interne).

SMTP : acheminer un mail

SMTP (RFC 821 en 1982, RFC 5321 en 2008) transfère des messages d’un utilisateur à un autre. L’enregistrement MX désigne les serveurs qui reçoivent le courrier d’un domaine.

ActeurRôle
MUAClient de messagerie (Thunderbird, Outlook, Mutt)
MTAServeur qui achemine (Postfix, Exim, Sendmail, Exchange)
MDADépose le message dans la boîte de l’utilisateur
PortUsage
25Historique, transfert entre serveurs (souvent bloqué en sortie par les FAI)
587Soumission de message, avec TLS
465SMTPS (SSL implicite)

Envoi manuel avec telnet

$telnet localhost 25
  • telnetClient TCP en mode texte.
  • localhostServeur de messagerie local.
  • 25Port SMTP.

Dialogue : HELO (ou EHLO) → MAIL FROM:<expéditeur> → RCPT TO:<destinataire> → DATA, corps du message, ligne contenant seulement un point → QUIT.

CommandeRôle
HELO / EHLOIdentification de l’émetteur (EHLO = ESMTP)
MAIL FROMDébut de transaction, expéditeur
RCPT TODestinataire (répétable)
DATACorps, terminé par CRLF.CRLF
VRFY / EXPNVérifier une adresse / développer une liste
RSET / QUITAnnuler la transaction / fermer
CodeSens
2xxSuccès (220 prêt, 250 OK, 221 fermeture)
3xxAttente d’informations (354 début du message)
4xxErreur temporaire, réessayer (450 boîte occupée)
5xxErreur permanente (500 syntaxe, 550 utilisateur inconnu)

ESMTP ajoute : 8BITMIME, AUTH, SIZE, STARTTLS, SMTPUTF8. SMTP n’authentifie pas l’expéditeur : MAIL FROM est facile à usurper. MIME étend l’ASCII 7 bits (pièces jointes, UTF-8, Base64, HTML). PGP apporte chiffrement et signature.

Paramètres de base de /etc/postfix/main.cf

#myhostname = mail.lapin.fr myorigin = /etc/mailname mydestination = $myhostname, localhost.$mydomain, localhost mynetworks = 127.0.0.0/8 [::1]/128
  • myhostname = mail.lapin.frNom de la machine.
  • myorigin = /etc/mailnameDomaine ajouté aux expéditeurs locaux.
  • mydestination = $myhostname, localhost.$mydomain, localhostDomaines livrés localement.
  • mynetworks = 127.0.0.0/8 [::1]/128Réseaux autorisés à relayer.

/etc/aliases : alias (puis newaliases). /etc/postfix/virtual : adresses virtuelles. master.cf : démons et ports. postfix reload recharge, postconf affiche les paramètres.
