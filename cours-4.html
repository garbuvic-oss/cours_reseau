Cours 4

Pare-feu, NAT et IPv6

Un pare-feu protège le réseau des intrusions, des paquets erronés et des dénis de service tout en laissant passer le trafic légitime.

Principes du filtrage

Pour chaque paquet : ACCEPT, DROP (silencieux), REJECT (réponse négative) ou LOG.

NiveauFonctionnement
StatelessPaquet par paquet : IP, ports, protocole. Aucun historique.
StatefulSuit l’état de la connexion : qui l’a initiée, si elle est établie.
Applicatif / DPIInspecte le contenu, détecte le tunneling ; coûteux en ressources.
  • SMURF / DoS : bloquer les broadcast ICMP, vérifier l’interface d’arrivée, limiter le débit.
  • Paquets martiens : adresses réservées non routables, souvent de l’usurpation.
  • ICMP : filtrer sans tout bloquer (garder types 3 et 4).

Netfilter et iptables

Netfilter est le module noyau ; iptables est l’outil qui le configure.

TableChaînesUsage
filter (défaut)INPUT, OUTPUT, FORWARDFiltrer, sans modifier
natPREROUTING, POSTROUTING, OUTPUTRéécrire adresses (sNAT, dNAT)
mangle–Modifier en-têtes et flags

NAT réécrit les adresses à la volée. sNAT (masquerading) réécrit la source pour sortir sur Internet ; dNAT réécrit la destination (redirection de port vers un serveur en DMZ).

Script de passerelle annoté

Passerelle à trois interfaces : publique eth2, privée eth1, DMZ eth0.

1. Activer le routage

#echo "1" > /proc/sys/net/ipv4/ip_forward
  • echo "1"Valeur à écrire.
  • >Écrit dans le fichier.
  • /proc/sys/net/ipv4/ip_forwardInterrupteur du noyau pour le routage IPv4.

2. Vider les règles

#iptables -t nat -F POSTROUTING
  • iptablesOutil de gestion des règles.
  • -t natTable nat (pour la ligne nat seulement).
  • -FFlush : supprime toutes les règles de la chaîne.
  • POSTROUTINGChaîne visée.

Le script répète la commande pour INPUT, OUTPUT, FORWARD (table filter) et PREROUTING (table nat).

3. Autoriser SSH

#iptables -A INPUT -p tcp --dport 22 -j ACCEPT
  • iptablesOutil.
  • -A INPUTAjoute en fin de la chaîne INPUT (paquets destinés à la machine).
  • -p tcpProtocole TCP.
  • --dport 22Port destination 22 (SSH). Même règle avec 80 pour le Web.
  • -j ACCEPTVerdict : accepter.

4. Autoriser les réponses de ping

#iptables -A INPUT -p icmp --icmp-type echo-reply -j ACCEPT
  • iptablesOutil.
  • -A INPUTChaîne INPUT.
  • -p icmpProtocole ICMP.
  • --icmp-type echo-replyUniquement les réponses d’écho (la machine peut pinger, mais pas être pingée).
  • -j ACCEPTAccepter.

5. Suivi de connexion

#iptables -A INPUT -m state --state ESTABLISHED,RELATED -j ACCEPT
  • iptablesOutil.
  • -A INPUTChaîne INPUT.
  • -m stateCharge le module de suivi de connexion.
  • --state ESTABLISHED,RELATEDConnexions déjà établies ou liées à une connexion existante : les réponses légitimes.
  • -j ACCEPTAccepter.

6. Interdire le reste depuis l’extérieur

#iptables -A INPUT -i eth2 -j REJECT
  • iptablesOutil.
  • -A INPUTChaîne INPUT, en dernier pour que les exceptions passent avant.
  • -i eth2Paquets entrant par l’interface publique.
  • -j REJECTRefuser en informant l’expéditeur (DROP serait silencieux).

L’ordre compte : la première règle qui correspond s’applique.

7. Redirection de port (dNAT)

#iptables -t nat -A PREROUTING -p tcp -d 193.49.118.7 --dport 8000 -j DNAT --to 192.168.7.79:80
  • iptablesOutil.
  • -t natTable nat.
  • -A PREROUTINGAvant la décision de routage, nécessaire pour changer la destination.
  • -p tcpProtocole TCP.
  • -d 193.49.118.7Destination d’origine : IP publique de la passerelle.
  • --dport 8000Port destination d’origine.
  • -j DNATRéécrit l’adresse de destination.
  • --to 192.168.7.79:80Nouvelle destination : serveur Web de la DMZ, port 80.

Le Web interne est ainsi joignable depuis l’extérieur sur le port 8000.

8. Masquerading (sNAT)

#iptables -t nat -A POSTROUTING -o eth2 -j MASQUERADE
  • iptablesOutil.
  • -t natTable nat.
  • -A POSTROUTINGAprès le routage, au moment de la sortie.
  • -o eth2Paquets sortant par l’interface publique.
  • -j MASQUERADERemplace l’adresse source par l’IP publique du routeur, même si elle change.

Le réseau privé accède à Internet derrière une seule adresse publique.

IPv6

  • Adresses de 128 bits, en-tête simple de taille fixe, autoconfiguration (SLAAC), mobilité et IPsec natifs.
  • Notation : fe80:a8b2:0000:0000:0000:020e:00ff:fe8f s’abrège en fe80:a8b2::20e:ff:fe8f (zéros de tête omis, un seul ::).
  • Entre crochets dans les applications : [2001:db8::1].
PréfixePortée
::1/128Loopback
fe80::/64Lien-local, non routable
fc00::/7Unique locale (privé)
2000::/3Globale, routable
::ffff:0:0/96IPv4 mappée en IPv6
ff02::1 / ff02::2Multicast : tous les nœuds / tous les routeurs

Attribuer une adresse IPv6

#ip -6 addr add 2001:db8::10/64 dev eth0
  • ip -6Famille IPv6.
  • addr addAjoute une adresse.
  • 2001:db8::10/64Adresse et longueur de préfixe.
  • dev eth0Interface concernée.

Routage : ip -6 route add ::/0 via <passerelle>. Activer : echo 1 > /proc/sys/net/ipv6/conf/all/forwarding. Tests : ping6, traceroute6.
